# Neon Snake

A polished, dependency-free Snake game made with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```

## Deploy

- **Netlify:** drag this folder into Netlify Drop, or connect the repository. No build command is needed; publish directory is `.`.
- **Vercel:** import the repository and choose “Other” / no framework. Leave the output directory blank.
- **GitHub Pages:** enable Pages for the repository’s main branch and set the folder to `/ (root)`.

Controls: arrow keys or WASD. Your best score is saved in the browser.
